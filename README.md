# Zomato Restaurant Data Analysis

This project analyzes the Zomato restaurant dataset to extract insights about restaurant ratings, pricing, cuisines, online ordering, and popular locations.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
- Data Cleaning
- Handling Missing Values
- Removing Duplicates
- Data Visualization
- Correlation Analysis
- Insights & Recommendations

## Key Insights
- Most restaurants support online ordering.
- North Indian cuisine is highly popular.
- Restaurant pricing has only a moderate impact on ratings.
- Areas like BTM and Koramangala have high restaurant density.

## Visualizations Included
- Rating Distribution
- Online Order Analysis
- Top Locations
- Top Cuisines
- Price vs Rating Graph
- Correlation Heatmap

## Dataset
Zomato Bangalore Restaurants Dataset
